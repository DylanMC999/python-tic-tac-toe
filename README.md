Python Tic-Tac-Toe
A simple two-player Tic-Tac-Toe game developed using Python.

About the Project
This project was created to practice fundamental Python programming concepts and gain experience building a complete game.
The game allows two players to take turns placing X's and O's on a 3×3 board.

Features
Two-player gameplay
3×3 game board
Turn-based player interaction
Win condition checking
Technologies Used
Python 3

How to Run
Install Python 3 on your computer.
Download or clone this repository.
Open a terminal in the project folder.
Run the following command:
python Tic_Tac_Toe.py
